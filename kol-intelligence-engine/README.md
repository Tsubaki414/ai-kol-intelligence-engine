# AI KOL Intelligence Engine

**Trial Task — Frontend Demo App**

A reusable KOL network intelligence platform built on top of a real Chinese + English AI+Crypto KOL database. Ships as a static React app; the upstream Python pipeline + Supabase backend live in the parent repo root.

> 680 classified KOLs · 27-node mutual-follow subgraph · three-layer parallel scoring (Quality ⨯ Cooperability ⨯ On-chain) · Outreach Priority Panel with referral-chain routing · live Claude agent mode

---

## Quick start

```bash
npm install
npm run dev    # dev server on http://127.0.0.1:5175 (strictPort)
npm run build  # production build → dist/
```

The app reads static JSON artifacts from `src/data/` — no backend required to run the frontend. Open `http://127.0.0.1:5175` after `npm run dev`.

## Data artifacts in `src/data/`

Generated by the Python pipeline in the parent repo. Regenerate with:

```bash
# From the repo root (requires Supabase env vars configured)
pipeline/.venv/bin/python scoring/export_kols_json.py
pipeline/.venv/bin/python scoring/export_graph_json.py
```

| File | Purpose | Size |
|---|---|---|
| `kols.json` | All 680 scoring-ready KOLs with Layer 1/2/3 scores, full score_traces JSONB, cooperability, estimated price, outreach angle | ~4 MB |
| `graph.json` | 680 nodes + 1157 edges (98 T1 mutual + 1059 T2 one-way), cluster summary, PageRank top-10, celebrity-filtered list | ~1 MB |
| `agent_responses.json` | 5 pre-computed Claude Sonnet 4.5 answers for the AI Agent page | ~13 KB |

## Scoring model (v3, redesigned 2026-04-09)

Three parallel main-line scores — never fused into a single "overall":

**Layer 1 · Quality Score (0-100)**
- Engagement Quality Ratio (30%) · Content Originality (25%) · Audience Authenticity (15%) · Sector Relevance (15%) · Network Position (15%)

**Layer 2 · On-chain Verification Score (0-100, independent display)**
- Wallet-Content Alignment (50%) · Activity Depth (25%) · Campaign Impact (25%)
- Only computed when `wallet_public=true`. Expected coverage ~15-20%. Null for bootstrap.

**Layer 3 · Cooperability Score (0-100)** — redesigned 2026-04-09
- **Contact Signal Strength (40%)** — deterministic regex on bio (email=100 > telegram=80 > collab keyword=60 > website=40 > DM default=10)
- **Promo Willingness (30%)** — scan cached tweets (explicit #ad/sponsor=90 > review+@mention=60 > authored-only=30 > null if no tweets)
- **Accessibility (30%)** — tier inverse (Nano=90 / Micro=70 / Macro=40 / Mega=15) + 15 bonus if mutual member

## AI Agent live mode

The `/agent` page ships with 5 pre-computed responses (free, instant). To unlock live mode:

1. Get a key from [console.anthropic.com/settings/keys](https://console.anthropic.com/settings/keys)
2. Paste it into the API Key input
3. The key is stored in `localStorage` only — never leaves the browser except for direct calls to `api.anthropic.com`
